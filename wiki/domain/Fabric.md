# Fabric

- **Definition:** The server side of the protocol: it hosts scopes, routes transfers, keeps ledgers, and enforces isolation.
- **Canonical name:** Fabric (never broker or hub).
- **Not:** A participant; the fabric writes only mutation records.
- **Example:** The reference fabric `grail-fabric` 0.1.0.
