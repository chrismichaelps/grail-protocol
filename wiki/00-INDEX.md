# Grail Vault

This vault is the design of the Grail protocol and of its reference fabric. The specification lives here, the contract page explains how one schema file drives every binding, and every source file has a page that says what it promises and why it is shaped that way.

## Maps of Content

- [[protocol/_MOC|Specification]] — the normative protocol, chapter by chapter.
- [[schema/grail.openapi|Contract]] — the OpenAPI document every binding, vocabulary, and problem code is generated from.
- [[architecture/_MOC|Architecture]] — layers, the contract pipeline, security, code style, and the governance dashboard.
- [[grammar/pudu|Pudu grammar]] — the pinned toolchain and the library surface in use.
- [[domain/_MOC|Domain]] — the vocabulary of scopes, participants, graphs, envelopes, and tokens.
- [[subsystems/_MOC|Subsystems]] — the bounded contexts.
- [[seams/_MOC|Seams]] — boundaries with more than one possible implementation.
- [[decisions/_MOC|Decisions]] — architecture decision records.
- [[src/_MOC|Source mirrors]] — one page per source file.
- [[test/_MOC|Test mirrors]] — one page per suite.
- [[tools/_MOC|Tools]] — the contract projector, the layer gate, the spacing gate, and mutation testing.
- [[handoffs/_MOC|Handoffs]] — work in flight and the next action.
- [[CHANGELOG|Changelog]] — the ledger of logic changes.
